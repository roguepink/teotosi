# テオトシ

グー・チョキ・パーのブロックが落ちてくる！となりに勝てば消える、じゃんけん落ちものパズル。

**遊ぶ: https://roguepink.github.io/teotosi/**

## しくみ(3D版・2026-11-17 作り直し)

- `index.html`(画面の作り) / `js/rules.js`(遊びの決まり) / `js/game.js`(進行・操作・音・文字) / `js/view3d.js`(3D で描く)
- 3D は three.js r186(`vendor/three/`・npm 公式の元のファイルを同梱し、部品チェック全部 ○)。importmap は使わない
- 3D が動かない機械(iOS 16.3 以前・WebGL なし)では、自動で 2D の画面になる。`#2d` で 2D を試せる / `#play` ですぐ始まる

## ルール

- 落ちたブロックが となり(上下左右)と じゃんけん。勝った相手は消える。落ちてきたほうは消えない
- 同じ手が4つ以上つながると「なかよし消し」
- 消えて落ちたブロックは、各列で いちばん下に着地したものが また勝負 → れんさ。続けて消すと コンボ(点数アップ)
- フィーバー: 消すとゲージがたまり、満タンで12秒 あいこ以外ぜんぶ勝ち・点数2ばい
- おだい: 「グーを6コ消す」など。クリアで 💣/🎁/⭐ のごほうびと点数
- ⭐ まわりを全部消す / 🎁 ふれた種類を盤から全部消す(5れんさでも もらえる) / 💣 まわり8マス / いわ は ⭐🎁💣 でだけ消える
- ピンチ(上から4段目まで積んだ)のときは たすけの💣
- レベル: 2で2コ → 3で3コと🎁 → 4で4コと💣 → 5からせり上がり → 8で5コの形と いわ。空が ひる→ゆうやけ→よぞら→うちゅう→オーロラ と変わる
- 終わると称号(じゃんけん みならい → … → じゃんけん 神)

## LINE で送る・ホーム画面に入れる

- 上のアドレスを LINE に貼れば、タイトルと絵つきの紹介が出る。タップするとすぐ遊べる
- **LINE の中で開いたときは、ホーム画面に入れられない。**メニューから「Safari で開く」(iPhone)/「他のアプリで開く」→ Chrome(Android)を選んでから入れる
  - iPhone(Safari): 共有ボタン →「ホーム画面に追加」 / Android(Chrome): メニュー(︙)→「アプリをインストール」
- 入れたあとは全画面で起動。一度開けば電波がなくても遊べる

## 直して公開するとき

- `main` に push すれば公開される(GitHub Pages)。電波のある人は、**次に開いたとき**に新しい版になる(`sw.js` は まずネットで最新を取りにいく)
- `sw.js` の `VERSION` を上げるのは、覚えるファイル(`FILES`)を変えたときだけ
