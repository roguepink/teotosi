# テオトシ

グー・チョキ・パーのブロックが落ちてくる！となりに勝てば消える、じゃんけん落ちものパズル。

**遊ぶ: https://roguepink.github.io/teotosi/**

## ルール

- 落ちてきたブロックが着地したら、となり(上下左右)のブロックと じゃんけん。**勝った相手は消える。落ちてきたほうは消えない**
- 消えたところに上のブロックが落ちたら、各列で いちばん下に着地したブロックが また勝負 → **れんさ**
- ⭐スター: まわりを全部消して、自分も消える / いわ: じゃんけんで消せない。⭐でだけ消せる
- 横1列そろい消しは しない(消えたら上が詰めるので、下の段が勝手にそろってしまうため)
- レベル: 2で2コの形 → 3で3コ → 4で4コ → 5からせり上がり → 7から いわ → 8で5コの形。速さも上がる
- 置く前に、消える相手が ぷるぷる ふるえて黄色いわくで光る

## 難しさの目安(自動プレイで確かめた・2026-11-09)

- でたらめに置く: レベル4〜13、45〜105手でおしまい
- いちばん多く消せる場所を選ぶ: レベル14〜15、約100手(速さの限界は入っていない)

## LINE で送る・ホーム画面に入れる

- 上のアドレスを LINE に貼れば、タイトルと絵つきの紹介が出る。タップするとすぐ遊べる
- **LINE の中で開いたときは、ホーム画面に入れられない。**メニューから「Safari で開く」(iPhone)/「他のアプリで開く」→ Chrome(Android)を選んでから入れる
  - iPhone(Safari): 共有ボタン →「ホーム画面に追加」 / Android(Chrome): メニュー(︙)→「アプリをインストール」
- 入れたあとは全画面で起動。一度開けば電波がなくても遊べる

## 直して公開するとき

- `main` に push すれば公開される(GitHub Pages)。電波のある人は、**次に開いたとき**に新しい版になる(`sw.js` は まずネットで最新を取りにいく)
- `sw.js` の `VERSION` を上げるのは、覚えるファイル(`FILES`)を変えたときだけ
